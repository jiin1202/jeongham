# 코치 시뮬레이션 평가

- `scenarios.py`: 가상 사용자 상황 15개와 채점 기준(must = 반드시 할 행동, mustNot = 하면 안 되는 행동)
- `run.py`: 로컬/배포 서버의 `/api/coach/`에 시나리오를 보내고 채점
- `summary.md`: 2026-11-23 v1·v2 결과 요약(gpt-5.4-mini, 45회)
- `result_rules_baseline.json`: 규칙 플래너 비교 결과(15/15, 시나리오와 규칙을 같은 사람이 설계해 낙관적)

모든 기록은 시뮬레이션이다. 보고서에 쓸 때 반드시 "시뮬레이션"이라고 표시한다.
미리보기 배포는 Vercel 로그인이 걸려 있어 스크립트 호출이 막힐 수 있으니 로컬 서버(`npm run dev`)로 돌린다.
